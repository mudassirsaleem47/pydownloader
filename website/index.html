YouTubeDownloader

Download YouTube videos in one click

A lightweight Windows app with a Chrome & Edge extension. Save videos as MP4, MOV or MP3 in the best quality available.

Download for Windows
Windows 10/11 · Free · No admin rights needed

Features

Best quality

Downloads the highest resolution available, or pick 1080p / 720p.

MP4, MOV & MP3

Save video or extract audio only. FFmpeg is bundled, nothing else to install.

Browser button

A download overlay appears right inside the YouTube player.

Multiple downloads

Run several downloads at once with speed, ETA and cancel for each.

Taskbar progress

See overall progress on the Windows taskbar icon.

Easy uninstall

Listed in Windows Apps & Features with a clean uninstaller.

How to install

  1. Download youtubedownloader_setup.exe and run it. If Windows SmartScreen warns you, click More info → Run anyway.
  2. Choose an install folder and click Install.
  3. When asked about the browser extension, click Yes, turn on Developer mode, then click Load unpacked and select the extension folder.
  4. Open any YouTube video and click MP4, MOV or MP3 on the player.
